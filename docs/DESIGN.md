## 0. Философия: «тактический терминал, а не сайт»

Экран логина и экран ожидания — это не веб-страницы, это **лицо клуба на 27-дюймовом мониторе в тёмном зале**.
Пять принципов, из которых выведено всё остальное:

| # | Принцип | Как читается в коде |
|---|---|---|
| 1 | **Кинематографичная глубина.** Живая фотография зала под несколькими слоями затемнения — никогда не плоский цвет и никогда не «фон-обои» без обработки | `lock-bg.png` + 4 слоя вейлов в `lock-screen.tsx` |
| 2 | **Один красный акцент.** `#e5352b` — единственный «горячий» цвет. Всё остальное — почти-чёрный, сталь и три статусных цвета | `--primary` в `globals.css` |
| 3 | **HUD, а не декор.** Уголки, скобки, тонкие линейки, чипы телеметрии — всё выглядит как интерфейс железа, каждая деталь что-то сообщает | `CornerBrackets`, `HudChip`, `.tick-corners`, `.hud-frame` |
| 4 | **Дышащий неон.** Свет никогда не статичен: он медленно пульсирует и обходит границы по кругу. Но всегда **тонкий** — обнимает контур, не раздувает силуэт | `.neon-ring`, `.neon-text`, `.neon-logo` |
| 5 | **Время — главный герой простоя.** Часы — самый крупный объект на обоих экранах: клуб читается издалека, как вокзальные табло | `font-clock` `7–9rem` |

Правило-фильтр для любого нового элемента: **«это выглядело бы уместно на HUD-е военного симулятора?»**
Если нет — переделываем.

## 1. Цвет

### 1.1 Палитра (ровно 5 групп, больше не добавляем)

| Роль | Токен | Значение | Где применять |
|---|---|---|---|
| Канва | `--background` | `#0a0a0b` | корень `<html>`, тело приложения |
| Поверхности | `--surface` / `--surface-2` / `--panel` | `#121216` / `#16161c` / `#0e0e12` | панели, карточки, модалки |
| **Акцент** | `--primary` / `--primary-hover` | `#e5352b` / `#ff4a40` | CTA, активное состояние, неон, иконки-акценты |
| Сталь | `--steel` / `--steel-2` | `#c7ccd2` / `#868d95` | вторичная графика, разделители |
| Текст | `--text-high` / `--text-medium` / `--text-low` | белый 94 % / 56 % / 34 % | заголовки / описания / микро-лейблы |

### 1.2 Статусы

| Токен | Значение | Смысл |
|---|---|---|
| `--success` | `#35c98b` | ПК готов, сессия активна, «Optimal», сильный пароль |
| `--warning` | `#f5b23a` | заканчивается баланс/время, средний пароль |
| `--danger` | `#e5352b` | ошибка ввода, блокировка (совпадает с `--primary` намеренно) |
| `--info` | `#6bb1e4` | нейтральные подсказки, единственный холодный цвет |

### 1.3 Служебные токены прогресса и зон

Эти токены **не расширяют палитру** — они переиспользуют уже существующие значения и нужны только для того,
чтобы «опыт», «монеты» и «зона ПК» читались одинаково на всех экранах.

| Токен | Значение | Где применять | Запрещено |
|---|---|---|---|
| `--xp` | `#6bb1e4` (= `--info`) | полосы и кольца прогресса уровня, Battle Pass | как цвет текста абзаца |
| `--coin` | `#f5c542` | баланс IMBA-коинов, цена в коинах, `Money tone="coin"` | как цвет фона панели |
| `--zone-vip` | `#f5c542` | чип зоны VIP | как заливка карточки ПК |
| `--zone-standard` | `#868d95` (= `--steel-2`) | чип зоны Standard | — |
| `--zone-ps5` | `#6bb1e4` | чип зоны PS5/консоли | — |

Зональные цвета живут **только в чипах и лейблах** (`Badge tone="vip" \| "ps5"`), никогда не становятся фоном
поверхности: иначе экран получает второй акцент и ломает принцип «один красный».

### 1.4 Жёсткие правила цвета

- Ни один экран не использует `text-white` / `bg-black` напрямую — **только токены**. Исключение: rgba-вейлы над медиа.
- Фиолетовый, розовый, бирюзовый как акценты — **запрещены**.
- Градиенты — только «прозрачный → красный → прозрачный» (тонкие линейки и вейлы). Красный↔белый — допустимо, потому что это одна температура.
- Меняешь фон элемента — обязан задать и цвет текста. Контраст текста на медиа проверяется на самом светлом кадре фона.

## 2. Типографика

Ровно **три гарнитуры**, каждая с одной задачей — четвёртую не добавляем.

| Токен | Гарнитура | Задача | Начертания |
|---|---|---|---|
| `--font-sans` | **Inter** | тело, описания, инпуты | 400–500 |
| `--font-display` | **Manrope** | заголовки, кнопки, лейблы, чипы | 500 / 600 / 700 |
| `--font-clock` | **Chakra Petch** | только большие часы и цифровая телеметрия | 500–700, `tnum` |

Подмножества `latin + latin-ext + cyrillic` у Inter и Manrope — заголовок на RU/LT/EN **одинакового размера и характера**, интерфейс не «прыгает» при смене языка.

### 2.1 Шкала и приёмы

| Класс/приём | Параметры | Где |
|---|---|---|
| Гигантские часы | `7rem` → `9rem` (xl), `leading-[0.85]`, `tabular-nums` | логин слева, attract по центру |
| H1 карточки | `2.1rem`, `font-bold`, `uppercase`, `leading-[0.95]`, `text-balance` | «WELCOME **BACK**» |
| Тело | `text-sm`, `leading-relaxed` (1.5–1.6) | подзаголовки, описания |
| `label-mono` | Manrope, `uppercase`, `letter-spacing 0.18em`, 9–11 px | «ACCESS TERMINAL», «LOCAL TIME», тикер |
| Разрядка attract | `tracking-[0.22em] … [0.35em]` | «NOW OPEN · 24/7», дата, подсказка |

**Правила:** акцентное слово в заголовке — красное + `.text-glow`, но **одно слово, не фраза**.
Терминальный каретка-курсор `_` c `.caret-blink` ставится только в конце главного заголовка логина.
Кегль ниже 14 px допустим исключительно для `label-mono` с разрядкой — обычный текст мельче 14 px запрещён.

## 3. Слоистость фона — «рецепт кинематографичности»

Самая ценная часть стиля. Любое новое медиа (видео, фото, слайдшоу из админки) **обязано** проходить через этот пирог,
иначе экран сразу выглядит как чужой шаблон.

### 3.1 Экран логина (5 слоёв)

1. **Медиа** — `object-cover`, `priority`, `sizes="100vw"`.
2. **Базовое затемнение** — `bg-black/45`.
3. **Холодная коррекция** — `rgba(8,10,18,0.35)`: гасит красный пересвет фотографии зала.
4. **Горизонтальный вейл** — `linear-gradient(90deg, 0.6 → 0.12 @45% → 0.78)`: чисто слева под часы, плотно справа под карточку.
5. **Вертикальный вейл** — `linear-gradient(180deg, 0.55 → 0 → 0 → 0.7)`: прижимает верх и низ кадра.
6. **`ParticleField`** — 10 красных искр `2–3 px`, всплывают 9–14 с, `opacity 0 → 0.5 → 0`. Детерминированные позиции (без `Math.random` при рендере) — никакого мерцания при гидрации.

### 3.2 Экран ожидания (6 слоёв)

1. **Медиа** — плейлист `muted mp4/webm` **или** Ken Burns-слайдшоу (`scale 1 → 1.12` за 11 с, кросс-фейд 1.6 с).
2. `bg-black/35`.
3. **Радиальный скрим** — `ellipse 62% 44% at 50% 47%`, `0.72 → 0.35 → 0`: тёмное «яйцо» точно под часами.
4. **Вертикальный вейл** — `0.8 → 0 → 0 → 0.92` (низ плотнее — под тикер).
5. **Скан-линии** — 1 px через 3 px, `opacity 0.06`, `mix-blend-overlay`: CRT/трансляционная текстура.
6. **HUD-скобки** — 4 уголка `40–56 px`, `border-white/20`, отступ `20–28 px`.

**Порог качества:** белый текст на любом кадре — контраст ≥ 4.5:1. Если админ загрузил светлое видео, плотность вейлов
поднимается через настройку затемнения (`0–90 %`), а не «на глаз».

## 4. Эффекты и материалы

| Утилита | Что делает | Когда использовать |
|---|---|---|
| `.glass` | 3-стоповый белый градиент 3.5 % → 0.6 %, `blur(10px)`, внутренний хайлайт сверху, тень `0 18px 40px -30px` | чипы телеметрии, лёгкие плашки |
| `.glass-strong` | то же + подложка `#101015`, `blur(18px)`, `--border-strong` | модалки (QR), важные оверлеи |
| `.panel` | сплошной `--panel`, без блюра | плотные карточки, длинные списки |
| `.neon-ring` | конический градиент красный↔белый, `1.5px` кромка, оборот **7 с**, `::after` с `blur(6px) opacity .55` | карточка логина, чипы, важные интерактивные блоки |
| `.neon-text` | «дыхание» текста 4.5 с, радиусы `1/3/7 px` — тонко и ярко | только большие часы |
| `.neon-logo` | «дыхание» логотипа 5 с через `drop-shadow` + две тени глубины | лого IMBA |
| `.text-glow` | `text-shadow 0 0 26px rgba(229,53,43,.5)` | акцентное слово заголовка |
| `.scanline` | красный луч 25 % высоты, проход 5 с | «сканирование» в загрузках/картах игр |
| `.marquee-track` | бесконечный сдвиг 40 с, пауза на hover | промо-тикер attract |
| `.shimmer` | косой блик 3.5 с | скелетоны загрузки |
| `.tick-corners` / `.hud-frame` | HUD-уголки `9–10 px` | карточки, панели, оверлеи |

**Скруглённость — «тактическая»:** `--radius-sm 3px`, `md 6px`, `lg 10px`, `xl 16px`. Круглые `rounded-full` — только у чипов и пилюль.

**Срезанный угол CTA** — подпись бренда: главная кнопка использует
`clip-path: polygon(0 0, 100% 0, 100% calc(100% - 12px), calc(100% - 12px) 100%, 0 100%)`
и «сheen»-блик, пробегающий слева направо за 700 мс на hover. Такой формы больше нет ни у одного элемента.

## 5. Композиция экранов

### 5.1 Логин — асимметричный сплит

```
┌──────────────────────────────────────────────┬───────────────────────┐
│  логотип (360–430 px, neon-logo)             │   [ EN | RU | LT ]    │  ← switcher: absolute top-right
│                                              │                       │
│  ── LOCAL TIME                               │  ╔═══════════════╗    │
│  02:06 :06        ← 7–9rem + neon            │  ║ ACCESS TERM.  ║    │  ← карточка max-w-md
│  Sunday, July 26                             │  ║ WELCOME BACK_ ║    │     neon-ring + blur-2xl
│                                              │  ║ [tabs][форма] ║    │     bg #0a0b10/80
│  (PC #17 READY)(Ping)(Display)(GPU)(Status)  │  ║ ENCRYPTED ·v2 ║    │     shadow 0 32px 90px
└──────────────────────────────────────────────┴──╚═══════════════╝────┘
    flex-1, hidden lg:flex, p-10 → xl:p-14           lg:w-[44%] min-w-[480px]
```

- Левая колонка — **личность станции** (`justify-between`: лого сверху, часы в центре, телеметрия внизу). На мобильном скрывается.
- Правая — **терминал доступа**. На мобильном становится единственной, лого — компактно сверху, часы + бейдж ПК — снизу.
- Верхняя кромка карточки: `1px` градиент «прозрачный → красный 0.8 → прозрачный». Подвал: `border-t`, `bg-black/30`, «ENCRYPTED SESSION» слева, `IMBA-SHELL v2.4` справа — подпись прошивки.

### 5.2 Экран ожидания — центрированная вертикаль

```
             IMBA лого (пульс 0.85↔1, 4 с)
             ● NOW OPEN · 24/7
                    ⋮
              0 2 : 0 6        ← двоеточие мигает 2 с
        ────────────────── 49  ← секунды как прогресс-линия минуты
            SUNDAY, JULY 26
                — ─ ▬          ← индикатор слайда (активный w-8)
        ( ▷ MOVE MOUSE TO UNLOCK )   ← пульс 2.4 с
                    ⋮
   (PC #17 READY)(Ping)(Display)(GPU)(Status)
── HAPPY HOURS 22:00—06:00 · −30% ······ бегущий тикер 40 с ──
```

`flex-col justify-between` + `pt-9 pb-16` — три яруса: идентичность, часы, HUD; тикер прижат к низу отдельным слоем `z-20`.

### 5.3 Единый низ обоих экранов

Идентичный ряд чипов телеметрии (`PC #17 · Ping · Display · GPU · Status`) — **главный шов, сшивающий два экрана в один продукт**.
Один и тот же компонент-паттерн: `glass neon-ring rounded-full px-3.5 py-1.5`, иконка `13 px`, лейбл `10 px uppercase tracking-widest text-low`, значение `12 px font-semibold tabular-nums`.

## 6. Движение

| Событие | Параметры |
|---|---|
| Вход блоков логина | `y: 16–24 → 0`, `opacity 0 → 1`, `0.7–0.8 s`, `easeOut`, задержки `0 / 0.15 / 0.3 s` — каскад |
| Смена вход↔регистрация | `x: ±24 → 0`, `0.25 s`, `AnimatePresence mode="wait"` |
| Пилюля активного таба / языка | `layoutId` + `spring`, `bounce 0.2`, `0.4–0.45 s` |
| Ошибка формы | shake `x: [0,-10,10,-8,8,-4,4,0]`, `0.5 s` |
| Уход в простой | карточка `y → 56`, `scale → 0.9`, `opacity → 0`, `0.6 s easeIn` + `pointer-events-none` |
| Появление attract | `opacity 0 → 1`, `1.2 s easeOut` — «свет гаснет», не щелчок |
| Выход из attract | `opacity → 0` + `blur(12px)`, `0.5 s easeIn` |
| Часы attract | вход `y 24 → 0`, `1 s`, задержка `0.4 s` |
| Пульсации | лого 4 с · двоеточие 2 с · подсказка 2.4 с · точка «онлайн» 1.6 с — **разные периоды намеренно**, чтобы не было маршевого синхрона |

**Правила:** ничего быстрее `0.2 s` (дёргается) и медленнее `1.2 s` для реакции на ввод (тормозит).
Бесконечные анимации — только `ease-in-out` и только у декора. Уважаем «меньше анимаций» из настроек пользователя:
периодические эффекты глушатся, функциональные переходы остаются.

## 7. Идентичность бренда

| Ассет | Применение |
|---|---|
| `imba-logo-full.png` | логин (360–430 px), attract (256–320 px), всегда с `.neon-logo` |
| `imba-mark.png` | компактные места: топ-бар лаунчера, favicon-контексты |
| `imba-wordmark.png` | узкие горизонтали, где знак не читается |

Логотип **никогда** не перекрашивается, не растягивается (`object-contain`), не кладётся на светлый фон без вейла
и не уменьшается ниже `40 px` по высоте.

Голос интерфейса — **лаконичный операторский**: «Unlock Station», «Access Terminal», «Encrypted session», «Move mouse to unlock».
Без восклицательных знаков, без маркетингового пафоса, без эмодзи. Тикер — единственное место с капсом и промо-тоном.

## 8. Что должна сохранять настраиваемость из админки

Функция `A11` («Оформление экранов клиента») даёт админу менять медиа и тексты — но **не право сломать стиль**.
Границы настраиваемости:

| Настраивается админом | Зафиксировано дизайн-системой |
|---|---|
| Медиа фона: видео / фото / слайдшоу / сплошной цвет | Слоёный пирог вейлов (§3) применяется всегда |
| Плотность затемнения `0–90 %`, размытие, точка фокуса | Минимальный контраст текста 4.5:1 — валидируется до публикации |
| Логотип клуба, название, приветствие, подпись, контакты | Гарнитуры, кегли, `label-mono`, разрядка, положение блоков |
| Плейлист attract: порядок, длительность, вкл/выкл слайдов | Композиция трёх ярусов, ряд чипов телеметрии, тикер внизу |
| Тексты тикера, инфо-блоки, языки EN/RU/LT | Красный `#e5352b` как единственный акцент, неон-система |
| Расписание тем (день/вечер/ночь/выходные) и назначение на клуб → зону → ПК | Тайминги движения и правило «разные периоды пульсаций» |

Для слабых ПК (`флаг «без видео»`) фон деградирует до статичного кадра **с тем же пирогом вейлов** — экран выглядит тише, но не иначе.

## 9. Оверлей FPS — стиль внутри игры

Оверлей (`C5.13`–`C5.19`) — самый «наглый» элемент продукта: он лежит поверх чужой графики. Поэтому:

- Форма — тот же `glass` чип с `rounded-md`, но **без `neon-ring`**: вращающийся свет в игре отвлекает.
- Типографика — `font-clock` + `tabular-nums`: цифры не «пляшут» при смене значений.
- Цифра значения — `--text-high`, подпись метрики — `label-mono` `9 px` `--text-low`.
- Цветовая индикация только у значения FPS: `--success` / `--warning` / `--danger` по порогам клуба.
- Фон `rgba(10,11,16,0.55)` по умолчанию, прозрачность регулируется игроком; фиксированные углы, отступ `16 px`.
- Никакого движения, кроме смены цифр. Ни пульсаций, ни блика, ни скан-линий.

## 10. Библиотека примитивов (F1.1–F1.20)

Стиль выше **уже упакован в компоненты**. Правило номер один для любого нового экрана:
**сначала ищем примитив, только потом пишем разметку руками.** Если нужного варианта нет — расширяем примитив
(новый `variant` / `tone` / `size`) и дописываем строку в эту таблицу, а не создаём локальную копию в папке экрана.

### 10.1 Поверхности и действия

### 10.5 Границы ответственности

- Примитив **не знает** про доменные данные: он принимает готовые строки и числа. Форматирование живёт в `lib/format.ts`
  (`formatEUR`, `formatCoins`, `formatDuration`), а не внутри компонента.
- Примитив не задаёт внешние отступы — их даёт родитель через `gap` (§Tailwind-правила).
- Любой примитив принимает `className` для расположения, но **не** для перекраски: новый цвет = новый `tone` в самом примитиве.

## 11. Витрина `/dev/kit`

Страница `app/dev/kit/page.tsx` (компоненты в `components/dev-kit/`) показывает **все примитивы во всех состояниях**
на реальном фоне продукта. Это рабочий инструмент, а не демо для заказчика:

- Доступна только в разработке — в `production` отдаёт `notFound()`.
- Путь без подчёркивания (`/dev/kit`, а не `/_dev/kit`): Next.js исключает `_`-папки из роутинга.
- Разделы витрины повторяют структуру §10 — поверхности и действия, ввод, данные и статусы, состояния загрузки.
- **Порядок работы:** меняешь примитив → проверяешь его на `/dev/kit` во всех вариантах → потом идёшь на экран.
  Новый примитив без секции в витрине считается незавершённым.
