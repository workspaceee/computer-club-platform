> Заполнила **чат-разведка**. Читает **чат-исполнение** и больше ничего: ни `PLAN.md`, ни `DESIGN.md`.

## 1. Что нужно сделать

Дословно из плана:

> **C4.6** Модал запуска: реальные шаги от AgentBridge — «Проверка обновлений» → «Выдача аккаунта» →
> «Вход в лаунчер» → «Запуск», прогресс, возможность отмены

Что за этим стоит в коде: сейчас шаги — **фикция**. `hooks/use-game-launch.ts` делает
`Promise.all([launchGame(id), setTimeout(3000)])` и прокручивает три хардкодных ключа таймерами по
1000 мс. `mockAgent.launchGame()` с его `onProgress` / `percent` / `signal` **не вызывается вообще** —
семь реальных шагов агента лежат мёртвым кодом. Пункт подключает настоящий поток прогресса, рисует
прогресс-бар и даёт отмену.

## 2. Готовность (Definition of Done этого пункта)

- [ ] `useGameLaunch()` вызывает `mockAgent.launchGame(gameId, { onProgress, signal })`; фейковый
      таймер `LAUNCH_TOTAL_MS` и `useEffect` с тремя `setTimeout` **удалены**.
- [ ] Чеклист в модале — четыре строки в порядке плана, каждая со своим статусом
      `pending` / `active` / `done`, статусы приходят из реальных тиков агента.
- [ ] Под чеклистом — `Progress` с `percent` агента, монотонный (значение никогда не падает).
- [ ] Кнопка «Отмена» в состоянии запуска: гасит агент через `AbortSignal`, закрывает диалог,
      снимает `launchingGameId`, поднимает **нейтральный** тост `games.launchCancelled` — не ошибку.
- [ ] `runningGameId` выставляется **только** после того, как агент вернул `GameLaunchHandle`.
- [ ] Ошибка агента → тост по `errors.<AgentErrorCode>`; ошибка API → прежний
      `games.launchFailed {code}`. Союз `AgentErrorCode` не расширяется.
- [ ] Быстрый запуск с карточки «Продолжить» (`continue-row.tsx`) работает как раньше и **без
      правок в самом файле** — он читает только `launch` / `launchingId` / `busy`.
- [ ] Три словаря (`en` / `ru` / `lt`) в паритете, `tsc --noEmit` чист.

## 4. Как это уже сделано рядом (эталон)

**Шаги агента, которые надо принять** — `lib/agent/mock-agent.ts`, `LAUNCH_STEPS` (строка ~396).
Читать файл не нужно, вот они целиком:

```ts
{ phase: 'queued',           step: 'queued',            percent:  4 }
{ phase: 'preparing',        step: 'checkingFiles',     percent: 18 }
{ phase: 'preparing',        step: 'syncingCloudSaves', percent: 32 }
{ phase: 'startingLauncher', step: 'startingLauncher',  percent: 52 }
{ phase: 'startingLauncher', step: 'signingIn',         percent: 66 }
{ phase: 'launching',        step: 'startingGame',      percent: 84 }
{ phase: 'launching',        step: 'waitingForWindow',  percent: 96 }
// затем emit('running', 100, 'running') и resolve(GameLaunchHandle)
// на провале: emit('failed', 100, 'failed') и throw AgentError
```

Полный проход — 3.6–8.5 с при `latencyFactor: 1`. Провал включается `config.launchFailureRate`
в том же файле (по умолчанию `0`).

**Группировка 7 → 4** (единственный источник истины, положить в `use-game-launch.ts`):

```ts
/** Строки чеклиста, в порядке показа. */
export type LaunchStepId = 'updates' | 'account' | 'launcher' | 'game'
export type LaunchStepStatus = 'pending' | 'active' | 'done'

export const LAUNCH_STEPS: readonly LaunchStepId[] = ['updates', 'account', 'launcher', 'game']

/** Шаг агента → строка чеклиста. */
const STEP_GROUP: Record<string, LaunchStepId> = {
  queued: 'updates',
  checkingFiles: 'updates',
  syncingCloudSaves: 'updates',
  startingLauncher: 'launcher',
  signingIn: 'launcher',
  startingGame: 'game',
  waitingForWindow: 'game',
  running: 'game',
}

/** Резерв, когда агент пришлёт шаг, которого мы не знаем: фаза закрытая, шаг — нет. */
const PHASE_GROUP: Record<GameLaunchPhase, LaunchStepId> = {
  queued: 'updates',
  preparing: 'updates',
  startingLauncher: 'launcher',
  launching: 'game',
  running: 'game',
  exited: 'game',
  failed: 'game',
}
```

`step` в `GameLaunchProgress` — `string | undefined`, поэтому `STEP_GROUP[p.step ?? ''] ?? PHASE_GROUP[p.phase]`.

**Монотонность и статусы.** `percent` берём через `Math.max` с предыдущим. Статус строки:

- `account` — из подтверждения сервера: `active`, пока `catalog.launchGame` не ответил, `done` после.
- остальные три — из индекса текущей группы агента: индекс меньше → `done`, равен → `active`,
  больше → `pending`.

Строки **независимы**, непрерывности не гарантируем: `catalog.launchGame` отвечает за 200–400 мс,
первый шаг агента приходит через 120–260 мс, так что на практике «Выдача аккаунта» гаснет в галочку
почти сразу. Выводить `account` из индекса агента нельзя — у агента такого шага нет вообще.

**Эталон обработки ошибки и отмены** — как в `hooks/use-extend-time.ts:120` и
`components/agent/native-panels.tsx:82`:

```ts
toast('error', t(`errors.${toAgentError(error).code}` as TKey))
```

Отмену **не** определяем по `AgentError.detail === 'aborted'`: по контракту (`lib/agent/bridge.ts`,
шапка) `detail` — только для логов и админки, игроку он не показывается. Отмена — факт клиента,
держим её локальным `cancelledRef`, союз кодов не расширяем.

**Порядок двух медленных вещей** (переписать шапку хука под это):

```ts
const controller = new AbortController()
const [, handle] = await Promise.all([
  // если клуб откажет — гасим агента, чтобы игра не поднималась после отказа
  launchGame(game.id).catch((err) => { controller.abort(); throw err }),
  agent.launchGame(game.id, { onProgress, signal: controller.signal }),
])
// только теперь машина занята
setRunningGame(game.id)
```

`agent` — `mockAgent` из `@/lib/agent/mock-agent`, ровно как в `hooks/use-agent.ts:32`
(`const agent = mockAgent`). Прямых `window` / WebSocket быть не может.

**Гейт агента.** Перед запуском проверить, что агент есть: `hooks/use-agent.ts` → `useAgent()`,
`status === 'ready' && capabilities.launchGames`. Если нет — **не** стартовать и поднять
`errors.agentUnavailable`. Фейковый успех запрещён (F5.4); кнопку «Позвать админа» добавит C4.8.

**Эталон вёрстки** — состояние запуска уже есть в `game-launch-modal.tsx` (ветка `launching`):
`role="status" aria-live="polite"`, `icons.check` (`text-success`) для сделанного, `icons.pending`
(`animate-spin text-primary`) для текущего, пустой `span` 3.5 для будущего. Сохранить эту разметку,
поменяв источник статуса и добавив под ней `Progress` и кнопку. Кнопка отмены — стиль существующей
«Отмена» из футера: `rounded-lg border border-border py-2.5 text-sm font-semibold text-text-high
transition-colors hover:bg-white/5`.

## 6. Подводные камни

- **«Выдача аккаунта» — не шаг агента.** Это серверная выдача (`catalog.grantHouseAccount`,
  зарезервирована в C2.13 под C4.7) и она **в** `OFFLINE_BLOCKED`, тогда как `catalog.launchGame` —
  вне. В C4.6 строку кормит подтверждение `catalog.launchGame`, вызова выдачи **нет**. C4.7 заменит
  источник строки и добавит офлайн-ветку на готовых ключах `games.houseAccountOffline*`. Не
  пытаться сделать C4.7 здесь: пропуск строки для игр без общего аккаунта и «все аккаунты заняты» —
  его работа.
- **Отмена не мгновенная.** Мок проверяет `signal.aborted` только между шагами, а `sleep()` не
  прерываем — значит после «Отмены» мок ещё до 2 с держит `state.running`, и повторный запуск в это
  окно упадёт с `gameAlreadyRunning`. Починить в `mock-agent.ts` внутри `launchGame`: гонка сна с
  сигналом (`Promise.race([sleep(...), abortPromise])`) и проверка `signal.aborted` сразу после.
  Правка на несколько строк, за пределы `launchGame` не выходить.
- **Escape по-прежнему не закрывает** диалог во время запуска (`closeOnEscape: !launching`) — так и
  оставить. Отмена старта, который уже идёт на машине, должна быть осознанной: только кнопка. Скрим
  тоже остаётся неактивным (`onDismiss={launching ? undefined : close}`).
- **Поведение честно меняется в двух местах**, и это ожидаемо, а не регресс: игра, которой нет на
  диске, теперь **не запускается** (`gameNotInstalled` от агента вместо прежнего фальшивого успеха),
  и запуск на месте без агента тоже отказывает. Тексты и «Позвать админа» — C4.8.
- **Высота.** Клубный экран — 693 px, диалог уже самый высокий в продукте (`OVERLAY_MAX_H` +
  внутренний скролл, обложка 160 px). Четыре строки + бар + кнопка должны влезать без скролла:
  `gap-2` между строками, бар `size="sm"`, отступы не раздувать.
- **Дизайн-запреты.** Только токены (`text-success`, `text-primary`, `bg-primary`, `text-text-low`),
  никаких hex/rgb/oklch, никаких `bg-black` / `text-white`. Иконки — только через `lib/icons.ts`
  (`icons.check`, `icons.pending`, `icons.close`), эмодзи запрещены. Неон не добавлять: свечение в
  диалоге уже есть на кнопке «Запустить», второй источник — нарушение тиров.
- **Утечки.** Хук должен снимать `launchingGameId` во всех выходах (успех, ошибка, отмена) и не
  писать состояние после размонтирования поверхности (`alive` / `useRef`, как в `use-agent.ts`).
- **Долг C4.5**, адресованный сюда, — только «шаги доработает C4.6». Больше ничего не унаследовано.

6. Языки: ru / lt / en — все четыре строки, тост отмены и `aria-label` бара переведены, ничего не
   обрезано.
