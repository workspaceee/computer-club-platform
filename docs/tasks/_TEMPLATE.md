```tsx

```

## 5. Данные и текст

- Мок-API: какая функция из `lib/mock/api/*`, какой ключ `useApi`, что в `EVENT_INVALIDATES`.
- Типы: какие из `lib/types/*` уже есть, какие добавить.
- Новые ключи i18n: список, и что они значат. Все три словаря — `en` / `ru` / `lt`.
- Числа/деньги/время: через `lib/money.ts` / `lib/time.ts`, в центах и секундах.
